# 论文初稿

更新：2026-10-31。当前版本为英文仿真研究初稿，不以最终 60 页为目标。

## 本稿主线

用面向实车的虚拟训练环境学习 RL 教师，替代人工驾驶提供逐样本动作示范，再通过监督学习训练适合资源受限开发板的学生模型。

- **RL 的任务**：从驾驶结果和奖励中学习教师，不直接训练随机森林。
- **教师选择**：PPO 算法 + MLP Actor–Critic；Actor 为 292→128→128→15，Critic 为 292→128→128→1，均有两层 128 单元 Tanh 隐藏层，已核对冻结模型。
- **学生选择**：随机森林提供可控制的树深、树数和 C++ 导出路径；单树用于检验更简单的模型是否足够。
- **数字孪生范围**：当前完成虚拟训练侧；实物标定、同步及模型保真度验证尚待完成。
- **低功耗目标**：训练留在主机，板端承担推理；Flash、RAM、时延、能耗和人工时间节省尚无实测结论。

摘要、引言、方法、结果讨论和结论围绕以上主线展开。原有正式题目保留，封面增加研究方向副标题。

## 当前结果范围

- 主对照为四个模型、四张地图、四种传感器条件、每格五次，共 320 次闭环测试。

- `ellipse_002` 用于验证与模型选择，正文未将其称为完全独立的最终测试集。

- R2 独立地图与学生起步恢复实验尚未完成；实车、目标板资源及实时性测量不在本稿结果中。
